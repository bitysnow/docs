## Text-to-Video Model Parameters

The following tables document only the `TextToVideo*TaskInput` structures used by `TextToVideoRequest`. In a request, pass the matching object for the selected model, such as `modelVQ1TaskInput` for `VQ1`.

Reference: [Baidu AI Cloud VOD Data Structures - TextToVideoVQ1TaskInput](https://cloud.baidu.com/doc/VOD/s/mm3h9frta#texttovideovq1taskinput) (official page updated on 2026-04-27).

## ModelTaskInput Parameters

Pass the modelTaskInput parameter field according to different model names

### VQ1

| Parameter           | Type    | Description                                                                                                                            |
| ------------------- | ------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| `prompt`            | string  | Text prompt for generation                                                                                                             |
| `duration`          | integer | Video duration in seconds. Supported value: `5`                                                                                        |
| `resolution`        | string  | Resolution. Supported value: `1080p`                                                                                                   |
| `style`             | string  | Style. Optional; default: `general`. Supported values: `general`, `anime`                                                              |
| `movementAmplitude` | string  | Movement amplitude. Optional; default: `auto`. Supported values: `auto`, `small`, `medium`, `large`                                    |
| `seed`              | integer | Random seed. Optional                                                                                                                  |
| `aspectRatio`       | string  | Aspect ratio. Optional; default: `16:9`. Supported values: `16:9`, `9:16`, `1:1`                                                       |
| `bgm`               | boolean | Whether to enable background music. Optional; default: `false`                                                                         |
| `offPeak`           | boolean | Whether to use off-peak mode. Optional. Tasks have a lower priority and may take longer, up to 18 hours, but are priced more favorably |
