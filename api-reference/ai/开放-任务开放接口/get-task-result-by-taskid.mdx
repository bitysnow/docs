---
openapi: get /task/result/{taskId}
---

## Response result

The status has the following values:
1.waiting: Tasks waiting to be executed
2.success: The task has been successfully executed
3.executing: Task in progress
4.fail: Task execution failed
5.invoking: Task in progress

Note that gpt-image supports base64 for generating images. If you choose base64, it will return resources.base64
